# PS Vita 1.00

**PS Vita 1.00 (barebones)**
- Native port at full speed, with sound, saves and all game modes
- No leaderboard, play timer or texture dumping; FPS counter off by default (SELECT + TRIANGLE)
- Needs HENkaku/Ensō, `libshacccg.suprx` in `ur0:data/` (ShaRKF00D), and your own The New Tetris (USA) ROM in `ux0:data/TNTRecompiled/` (MD5 `7a28179b00734c9aa0f0609fafaafd5f`)
- Known issue: the main menu lags; gameplay is unaffected


No ROM or game data is included.
